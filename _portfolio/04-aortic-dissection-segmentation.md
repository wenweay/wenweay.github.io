**Team project, Politecnico di Milano (2025)**

* Built an end-to-end semantic segmentation pipeline for type B aortic dissection (TBAD) images affected by non-uniform noise, using non-local means denoising and edge detection as preprocessing.
* Developed a lightweight enhanced U-Net with a pretrained ResNet50 encoder via transfer learning.
* Addressed severe class imbalance with a compound weighted cross-entropy and Dice loss, enabling automatic segmentation and quantitative analysis of the aortic true and false lumens.
